# Projected Survival with Trastuzumab Deruxtecan vs Trastuzumab Emtansine in Residual HER2-Positive Early Breast Cancer

This is the code base for the simulation model comparing outcomes for adjuvant trastuzumab deruxtecan (T-DXd) versus trastuzumab emtansine (T-DM1) in patients with residual HER2-positive early breast cancer.

Input data are all contained within the R code; see the supplemental information accompanying the manuscript for a detailed description of the input parameters and methods. The life table located in the data folder is the only other needed file to run the model.
